Dataverse Label Translator Terms of Use

Dataverse Label Translator is provided by PhuocLe as a free Dataverse and Dynamics 365 admin utility. There is no paid license, trial expiration, or publisher-managed license requirement for this AppSource release.

Free Use

You may install, deploy, copy, and use the app in any number of your own Dataverse or Dynamics 365 environments.

No Publisher Backend

The app does not send customer data, labels, metadata, API keys, telemetry, or usage data to a PhuocLe or Dataverse Label Translator publisher server. The app has no publisher-controlled backend server for data collection.

AI-Assisted Translation

When you run Auto Translate, selected labels and metadata text may be sent directly from your browser or client to the AI provider endpoint configured by you. AI provider endpoint, model, key, cost, quota, retention, privacy, security, and compliance are your responsibility. Use AI output at your own risk and review translations before saving.

App Settings Storage

AI settings are stored in the customer's Dataverse environment as an app settings web resource. Treat configured provider values as sensitive according to your organization policy.

Dictionary Data

Translation dictionary data is stored in your Dataverse environment. You are responsible for cleanup and governance of customer-owned data.

No Warranty

The app is provided as-is, without warranty. Back up your solutions and metadata before making translation changes.
